Привязка аккаунта

Valorant — HenrikDev API
Данные берутся через сторонний сервис HenrikDev API (community-проект, не от Riot). Нужен бесплатный ключ: зайди на страницу выдачи ключей HenrikDev, войди через Discord и создай ключ (Basic — бесплатно). Ключ хранится только в этом браузере (localStorage) и уходит только к HenrikDev API.
